# Iris Dataset

來源：UCI Machine Learning Repository，Iris Dataset（ID 53）  
網址：https://archive.ics.uci.edu/dataset/53/iris  
DOI：https://doi.org/10.24432/C56C76  
授權：Creative Commons Attribution 4.0 International (CC BY 4.0)

`raw/` 保存 UCI 原始下載檔案；`iris.csv` 是加入欄名後供本專案直接分析的版本，資料列內容取自 `raw/bezdekIris.data`。

欄位：

| 欄位 | 角色 | 型態 | 單位 |
|---|---|---|---|
| `sepal_length_cm` | 特徵 | 連續數值 | cm |
| `sepal_width_cm` | 特徵 | 連續數值 | cm |
| `petal_length_cm` | 特徵 | 連續數值 | cm |
| `petal_width_cm` | 特徵 | 連續數值 | cm |
| `species` | 目標分類 | 類別 | — |

分類為 `Iris-setosa`、`Iris-versicolor`、`Iris-virginica`，各 50 筆，共 150 筆。
